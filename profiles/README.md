# Perfiles de usuario

Este directorio guarda contenido personal y de referencia del autor para que no se mezcle con la configuración base del proyecto.

## Qué va aquí

- wallpapers personales;
- configuraciones de estado de Noctalia;
- archivos locales de usuario que no deben copiarse como plantilla de instalación.

## Qué NO es parte del instalador base

Los archivos dentro de este directorio no se consideran configuraciones reutilizables para un usuario nuevo. Son snapshots del entorno personal del autor y sirven como referencia para llevar el mismo estilo sin forzar rutas del autor en la instalación general.

## Cómo usarlo

- El instalador base debe seguir siendo portable.
- El contenido del perfil del autor puede usarse como referencia manual para replicar un look personalizado, pero no debe reemplazar la plantilla general.
- Si un usuario quiere conservar las mismas configs, puede copiarlas a su `$HOME` manualmente o a partir de su propio backup.

## English

# User profiles

This directory keeps the author's personal and reference files separate from
the project's base configuration.

## What belongs here

- Personal wallpapers.
- Noctalia state and settings snapshots.
- Local user files that should not be copied as installation defaults.

## Not part of the base installer

Files here are not considered reusable defaults for a new user. They are
snapshots of the author's environment, useful as a reference for the same look
without forcing the author's paths onto a general installation.

## How to use the profile

- Keep the base installation portable.
- Use the author's profile as an optional reference for a customized look; do
	not treat it as the general template.
- To keep the same settings, copy them into your own `$HOME` or restore them
	from your own backup.
